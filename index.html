Displays 2025Journal期刊

ITSRN++: Stronger and Better Implicit Transformer Network for Continuous Screen Content Image Super-Resolution

Sheng Shen, Huanjing Yue, Jingyu Yang, Kun Li

Arbitrary-scale screen-content super-resolution with a periodic-modulated implicit transformer, plus the SCI2K dataset.周期调制的隐式 Transformer 实现屏幕内容任意倍率超分，并构建 SCI2K 数据集。

Details详情

The journal extension of ITSRN. It modulates pixel features with a periodic function before the implicit transformer, so one network can upsample screen content by any ratio, and adds a dual-branch backbone mixing self-attention with depth-wise convolution to capture both sharp edges and large repeated structures. SCI2K contains 2,000 screen-content images at 2K resolution.

ITSRN 的期刊扩展版。在隐式 Transformer 之前用周期函数调制像素特征，让同一个网络按任意倍率放大屏幕内容；骨干用自注意力与深度卷积并联的双分支，同时刻画锐利边缘与大范围重复结构。SCI2K 含 2000 张 2K 分辨率的屏幕内容图像。

arXiv 2024Preprint预印本

DeeDSR: Towards Real-World Image Super-Resolution via Degradation-Aware Stable Diffusion

Chunyang Bi, Xin Luo, Sheng Shen, Mengxi Zhang, Huanjing Yue, Jingyu Yang

Degradation-aware representations steer Stable Diffusion for real-world super-resolution.用“退化感知”表示引导 Stable Diffusion，做真实场景超分。

Details详情

A text prompt says little about how an image was damaged, so diffusion-based restorers often return wrong semantics on severely degraded inputs. DeeDSR first learns a degradation-aware representation of the low-quality input with contrastive learning, then feeds it to Stable Diffusion together with the image.

文本提示几乎说不清图像“怎么坏的”，扩散修复模型在重度退化下常恢复出错误语义。DeeDSR 先用对比学习从低质量输入中学到退化感知表示，再与图像一起注入 Stable Diffusion。

IJCAI 2024Conference会议

Efficient Screen Content Image Compression via Superpixel-Based Content Aggregation and Dynamic Feature Fusion

Sheng Shen, Huanjing Yue, Jingyu Yang

Superpixel-based content aggregation makes learned screen-content compression efficient — the first learned codec comparable to VVC-SCC.基于超像素的内容聚合让学习式屏幕内容压缩更高效，首个可与 VVC-SCC 相当的学习式方法。

Details详情

Screen content has many repeated patterns that a plain convolutional codec cannot exploit, while global self-attention is too heavy. We group similar pixels into superpixels and aggregate content over them to capture non-local redundancy cheaply, and fuse features dynamically in the entropy model. It beats six learned codecs on three screen-content datasets.

屏幕内容有大量重复模式，普通卷积编码器用不上，全局自注意力又太重。我们把相似像素聚成超像素并在其上聚合内容，以很小代价利用非局部冗余，并在熵模型中做动态特征融合；在三个屏幕内容数据集上超过六种学习式编码方法。

ICCV 2023Conference会议

Dec-Adapter: Exploring Efficient Decoder-Side Adapter for Bridging Screen Content and Natural Image Compression

Sheng Shen, Huanjing Yue, Jingyu Yang

A tiny decoder-side adapter lets a natural-image codec compress screen content well, at very low extra cost.解码端的轻量适配器，以很低的额外代价让自然图像编码器高效压缩屏幕内容。

Details详情

Dec-Adapter freezes a codec pretrained on natural images and tunes only a small depth-wise / point-wise bottleneck attached to the decoder's residual blocks; its few parameters are transmitted along with the bitstream.

冻结在自然图像上预训练的编码器，只训练挂在解码端残差块上的小型深度卷积/逐点卷积瓶颈结构，少量参数随码流一起传输。

NeurIPS 2021Conference会议

Implicit Transformer Network for Screen Content Image Continuous Super-Resolution

Jingyu Yang, Sheng Shen, Huanjing Yue, Kun Li

An implicit transformer that upsamples screen content by any ratio while keeping thin edges sharp.隐式 Transformer 以任意倍率放大屏幕内容，同时保持细线边缘锐利。

Details详情

Low- and high-resolution pixel coordinates act as the key and query of a transformer; from the coordinates alone the network predicts the weights that turn neighbouring features into a pixel, avoiding the smoothing of shared convolution filters.

把低分辨率与高分辨率像素坐标分别作为 Transformer 的 key 与 query，只靠坐标预测把邻近特征变换成像素的权重，避免了共享卷积核带来的平滑。

JCST 2020Journal期刊

Reference Image Guided Super-Resolution via Progressive Channel Attention Networks

Huan-Jing Yue, Sheng Shen, Jing-Yu Yang, Hao-Feng Hu, Yan-Fang Chen

Matched patches from a high-resolution reference photo guide progressive, attention-based upsampling.用高分辨率参考图中匹配到的图块，引导基于注意力的渐进式上采样。

Details详情

Patches are matched between the low-resolution input and a reference of the same scene; the network then upsamples ×2 per level, feeding matched reference patches into each level, with channel attention computed from a learned weighted pooling.

先在低分辨率输入与同场景参考图之间做图块匹配，再逐级 ×2 上采样，并把匹配到的参考图块送入每一级；通道注意力的权重来自可学习的加权池化。
